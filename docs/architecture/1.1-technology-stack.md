# Technology Stack Selection & Setup

This document describes the technology choices and setup for Sensei OS.

## Overview

Sensei OS uses a modern, production-ready technology stack designed for:
- **Performance**: Fast response times and efficient resource usage
- **Scalability**: Horizontal scaling capabilities for growing workloads
- **Maintainability**: Clear separation of concerns and well-documented APIs
- **Security**: Industry-standard security practices built-in

## Setup Instructions

### Prerequisites

- Docker 24.0+
- Docker Compose 2.20+
- Node.js 20+ (for local frontend development)
- Python 3.11+ (for local backend development)

### Quick Start

1. **Clone and configure environment:**
   ```bash
   cp .env.example .env
   # Edit .env with your settings
   ```

2. **Start all services:**
   ```bash
   docker-compose up -d
   ```

3. **Access the application:**
   - Frontend: http://localhost:3000
   - API: http://localhost:8000
   - API Docs: http://localhost:8000/docs
   - MinIO Console: http://localhost:9001

### Local Development

#### Backend
```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
uvicorn sensei.main:app --reload
```

#### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Running Tests

#### Backend Tests
```bash
cd backend
pytest -v --cov=src/sensei
```

#### Frontend Tests
```bash
cd frontend
npm run test
npm run test:e2e
```

## Configuration

All configuration is done via environment variables. See `.env.example` (the
canonical environment contract — single source of truth for Compose, Helm and
Rust) for the complete list.

### Required Variables (Rust services)

| Variable | Description |
|----------|-------------|
| `DATABASE_URL` | PostgreSQL connection URL (derived from `POSTGRES_*` in Compose/Helm) |
| `JWT_SECRET` | 32+ character secret for JWT signing |
| `SENSEI_CEO_PASSWORD` | Password for the seeded CEO account (no default) |

### Optional Variables (Rust services)

| Variable | Default | Description |
|----------|---------|-------------|
| `SENSEI_ENV` | `development` | Environment (development/dev, staging/test, production/prod — parsed strictly) |
| `LOG_LEVEL` | `info` | Logging verbosity (alias: `SENSEI_LOG`) |
| `CORS_ALLOWED_ORIGINS` | localhost list | Comma-separated allowed CORS origins |
| `API_HOST` / `API_PORT` | `0.0.0.0` / `8080` | API bind address/port |
| `NATS_URL` | `nats://localhost:4222` | Event bus URL |
| `JWT_ACCESS_TTL_MINUTES` | `15` | Access-token lifetime in minutes |

## Security Considerations

1. **Secrets Management**: Never commit secrets to version control
2. **TLS**: All production traffic must use HTTPS
3. **Authentication**: JWT with short-lived access tokens
4. **Authorization**: Role-based access control (RBAC)
5. **Input Validation**: All inputs validated via Pydantic schemas
