- **One-click deep-dives** into any area of concern

## 2. First Login & Account Setup

### Initial Login Process

1. **Navigate to**: `https://your-company.sensei-os.com`
2. **Enter credentials** provided by your IT administrator
3. **Complete MFA setup** (Multi-Factor Authentication is mandatory for CEO accounts)
4. **Set your PIN** for quick mobile access

### MFA Configuration Options

```
Recommended: Authenticator App (Google Authenticator, Authy, Microsoft Authenticator)
Alternative: Hardware Security Key (YubiKey)
Backup: SMS codes (less secure, emergency use only)
```

### Profile Setup Checklist

- [ ] Upload professional photo (appears in org chart and communications)
- [ ] Verify contact information (email, phone)
- [ ] Set notification preferences
- [ ] Configure working hours for smart notifications
- [ ] Add executive assistant for delegation
- [ ] Set preferred dashboard layout
- [ ] Configure mobile app

### Setting Up Your Executive Assistant

1. Go to **Settings → Delegation**
2. Add your EA's email address
3. Configure delegation permissions:
   - View calendar items
   - Draft responses (require your approval)
   - Manage meeting requests
   - Filter notifications

## 5. Persona Switching

### What is Persona Switching?

As CEO, you can **temporarily view the system as any role** sees it. This helps you:

- Understand employee experience
- Identify UI/UX issues
- Verify access controls are appropriate
- See exactly what information is visible to each role

### How to Switch Personas

1. Click your **profile avatar** in top right
2. Select **Switch Persona**
3. Choose from available personas:

```
┌────────────────────────────────────────┐
│         SWITCH PERSONA                 │
├────────────────────────────────────────┤
│ 👔 CEO (Current)                       │
│ 🏭 General Manager                     │
│ 💼 Sales                               │
│ 🔧 Operator                            │
│ ✓  Quality                             │
│ 👥 HR                                  │
│ 💰 Accountant                          │
│ 📦 Warehouse                           │
│ 👷 Supervisor                          │
│ 🔨 Maintenance                         │
└────────────────────────────────────────┘
```

### Important Notes on Persona Switching

- **All actions are still logged as you** (CEO) with persona context
- You cannot escalate permissions while in a persona
- A **banner** indicates active persona: `👁️ Viewing as: Operator`
- Press `Esc` or click **Exit Persona** to return

### Audit Trail for Persona Usage

Every persona switch is logged:

```json
{
  "event": "persona_switch",
  "user_id": "ceo-uuid",
  "user_name": "Jane Smith",
  "original_role": "ceo",
  "target_persona": "operator",
  "timestamp": "2026-01-11T10:30:00Z",
  "session_id": "abc123"
}
```

## 6. Key Metrics & KPIs

### CEO-Level Metrics

#### Financial Metrics

| Metric | Description | Update Frequency |
|--------|-------------|------------------|
| Revenue | Current month/quarter/year | Daily |
| Gross Margin | % and $ | Daily |
| EBITDA | Earnings before interest, taxes, depreciation | Weekly |
| Cash Position | Current cash and equivalents | Daily |
| AR Aging | Receivables by age bucket | Daily |
| Working Capital | Current assets - liabilities | Weekly |

#### Operational Metrics

| Metric | Description | Target |
|--------|-------------|--------|
| OTD (On-Time Delivery) | % orders shipped on time | ≥95% |
| Quality PPM | Defects per million | ≤1000 |
| OEE (Overall Equipment Effectiveness) | Equipment utilization | ≥85% |
| Inventory Turns | Annual inventory turnover | ≥12 |
| Lead Time | Quote to ship average | ≤14 days |

#### People Metrics

| Metric | Description | Target |
|--------|-------------|--------|
| Headcount | Total employees | As budgeted |
| Turnover | Annual voluntary turnover | ≤10% |
| Training Compliance | Certifications current | ≥98% |
| Safety Incidents | OSHA recordables YTD | 0 |
| Engagement Score | Quarterly survey | ≥80% |

### Setting Up Metric Alerts

1. Navigate to **Settings → Alerts**
2. Click **Add Alert**
3. Configure:
   - Metric to monitor
   - Threshold (above/below)
   - Alert recipients
   - Alert channel (email, SMS, in-app)

**Example Alert Configuration**:
```yaml
Metric: OTD (On-Time Delivery)
Condition: Falls below 92%
Severity: Critical
Notify: CEO, GM, Operations Director
Channels: Email, SMS, Push Notification
```

## 14. Security & Audit Trail

### Your Security Responsibilities

As CEO, you have access to sensitive data. Remember:

- **Never share credentials** (use delegation instead)
- **Log out** when leaving devices unattended
- **Report suspicious activity** immediately
- **Review audit logs** monthly for your account

### Accessing Audit Logs

1. Navigate to **Admin → Audit Logs**
