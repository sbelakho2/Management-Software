# Organizational Memory

Tiers (item 42): personal / role / process / site / corporate. `organizational_memory`
(migration 117) anchors role-tier memory to the role SLOT and process-tier memory to
the process — employee departure never deletes it (A7).

Promotion is deterministic or reviewed (A8/A18):

```
operator comment → observation
                 → repeated      (occurrence_count ≥ 2 — deterministic, no model)
                 → proposed      (reviewed act)
                 → approved      (human gate; approving an un-proposed memory is rejected)
```

The AI proposes; it never unilaterally promotes (item 14). Lessons carry a context
signature so cross-site transfer is an EXPERIMENT with local verification (items 19/46).
